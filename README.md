# Linear Regression 📈

This project demonstrates how to implement **Linear Regression** using Python, including:
- Implementation from scratch using mathematical formulas.
- Comparison using the scikit-learn library.

## 📂 Directory Structure
- SimpleLinearRegression : Simple linear regression example.
- GradientDescent : Implementation using the Gradient Descent algorithm.
- Sklearn : Implementation using the scikit-learn library.
- CompleteLinearRegression : Full version with visualization.
